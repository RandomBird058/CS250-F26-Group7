Integration

What we are testing: Sending an image over wifi from ImageCapture to CameraInterface

"""
This integration test checks the ability of a camera to properly take a photo and remotely send an image to the server's CameraInterface. The test begins right after ImageCaptures take_picture() is called, which tests if the image has properly been captured. After this process, CameraInterface tests if the image sent after post_image() call has been properly received. 

These tests are necessary to ensure that the functions in ImageCapture and CameraInterface properly work across WiFi, with any errors in both the taking and the sending of a photo getting caught, which ensures that the image is captured successfully and sent through the database to warn of any potential changes. 
""" 

# Testing ImageCapture functions
# Capture an image
image: Image = ImageCapture.take_picture()

# Ensure the image was captured
if image is null:
	return FAIL

# Send the image to the CameraInterface
ImageCapture.post_image(image)


# Testing CameraInterface functions
# Wait for the image to be processed
time.sleep(100)

# Ensure the CameraInterface received an image by checking for it in the database
if EvaluationSystem.get_image(image) is null:
	return FAIL

return PASS


System


What we are testing: The workflow from the camera taking a picture all the way to sounding the alarm. We are ensuring that if the camera takes a picture with an alarming state to the bluff, the alarm sounds.

The camera takes a picture of the bluff in a bad condition (Or we feed it an alarming image). The camera then sends the picture over wifi to the camera interface in the server. The interface sends the image to the evaluation system. The evaluation system sounds the alarm and sends an alert to all subscribed.
