"""
This unit test tests two components of update_resolution() in CameraConfig. The first test checks the lower bounds of any width and height inputted to ensure that no measurement is less than or equal to zero. The second test then checks if the resolution measurements that were stored into CameraConfig copied over successfully.

The first test is necessary in order to first check if the input provided by the user is possible to implement for the resolution, as zero and lower could error the image capture software when inputted into the resolution. The second test is also necessary to confirm that the resolution config has been copied over successfully. 

The expected output is a resolution that equals the valid input provided. A test fails if an invalid resolution is inputted, or a value was stored incorrectly. 
"""

# Making test values
test_width: int = 10
test_height: int = 10

CameraConfig.update_resolution(test_width, test_height)

# Test bounds
if CameraConfig.width <= 0 or CameraConfig.height <= 0:
	return FAIL

# Test if values were copied over correctly
if CameraConfig.width != test_width or CameraConfig.height != test_height:
	return FAIL

return PASS
